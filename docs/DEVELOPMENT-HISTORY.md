# Geliştirme geçmişi

Kaynak: “Winamp tarzı MP3 player oluştur” sohbeti ve eldeki kaynak/teslim dosyaları.

1. **İlk talep:** Winamp'a benzeyen müzik oynatıcı ve klasik Winamp tarzı tema.
2. **Web oynatıcı:** Koyu metalik görünüm, yeşil ekran, çalma listesi, klasik kontroller ve yerel dosya seçimi/sürükleme eklendi. Web sürümü yayımlandı; bağımsız HTML teslimi hazırlandı.
3. **macOS isteği:** Kullanıcı web sayfası yerine macOS uygulaması istedi.
4. **Yerel uygulama:** AppKit/WKWebView kabuğu, paket içi HTML, yerel çoklu dosya seçimi ve pencere komutları eklendi. Apple Silicon ve Intel paketi hazırlandı.
5. **Kontrol:** macOS'ta dosya ekleme ve ses oynatma doğrulandı. Güncel uygulama metadata'sı 1.0 / Build 1'dir.

Bu depo mevcut kaynakların aktarımıdır. Sohbetler ve kaynak dosyaları dışında özgün eski Git geçmişi yoktur; yapay commit geçmişi oluşturulmaz.
